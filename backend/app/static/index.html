Telegram ingestion

Авточтение каналов/чатов через Bot API (проще) или Telethon. Настраивается через переменные окружения backend.

Проверка Telegram...
Что нужно, чтобы подключить Telegram
  • Проще: TELEGRAM_BOT_TOKEN + TELEGRAM_SOURCES
  • Альтернатива: TELEGRAM_API_ID + TELEGRAM_API_HASH + TELEGRAM_SESSION_STRING
  • TELEGRAM_SOURCES: username/id/ссылки каналов и чатов через запятую
