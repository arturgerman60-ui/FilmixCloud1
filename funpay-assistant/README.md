# FunPay Assistant

Десктоп‑программа для продавцов **FunPay**: авто‑поднятие лотов, авто‑ответчик
и авто‑выдача цифровых товаров (ключи, тексты). Готовый к продаже продукт.

- Windows‑приложение **без установки Python** (Python зашит внутри `.exe`).
- Установка через привычный `FunPayAssistant-Setup.exe`.
- Демо‑режим работает «из коробки» — можно показать покупателю сразу.
- Защита лицензией Ed25519 (см. `SELLING.md`).

---

## Для покупателя: как пользоваться

1. Скачайте и запустите **`FunPayAssistant-Setup.exe`** → «Далее» → «Установить».
2. Откройте **FunPay Assistant** с рабочего стола.
3. Вкладка **Настройки** → вставьте свой `golden_key` и снимите «Демо‑режим»
   (как получить ключ — ниже). Сохраните.
4. Вкладка **Шаблоны и ключи** → впишите склад ключей (по одному в строке) и
   тексты авто‑ответов. Сохраните.
5. Вкладка **Панель** → **▶ Запустить**. Программа сама поднимает лоты,
   отвечает на сообщения и выдаёт товар после оплаты.

### Как получить golden_key
1. Войдите на `funpay.com` в браузере.
2. `F12` → Application → Cookies → `funpay.com` → скопируйте значение
   `golden_key`.
3. Вставьте в настройках программы (хранится в зашифрованном виде на вашем ПК).

> Демо‑режим не требует ключа — события имитируются для проверки работы.

## Как получить готовый `.exe` (для продавца)

Сборка происходит автоматически на GitHub Actions (Windows‑раннер):

1. Запушьте папку `funpay-assistant/` в репозиторий (workflow уже включён:
   `.github/workflows/build-windows.yml`).
2. Вкладка **Actions** → workflow «Build FunPay Assistant (Windows)» →
   дождитесь зелёной галочки.
3. Раздел **Artifacts** → скачайте **`FunPayAssistant-Setup`**
   (это и есть готовый установщик) или **`FunPayAssistant-exe`**.

Собрать вручную на своём Windows‑ПК:
```bat
cd funpay-assistant
pip install -r requirements.txt pyinstaller
pyinstaller build\funpay_assistant.spec --noconfirm
:: затем Inno Setup:
iscc build\installer.iss
```

## Важно про FunPay
FunPay не имеет официального API. Живой режim работает через `golden_key` по
неофициальным эндпоинтам (как открытые боты Cardinal/Vertex). Верстка сайта
иногда меняется — при сбоях включите демо‑режим и обновите селекторы в
`src/funpay_assistant/funpay_client.py`. Инструмент рассчитан на **честных
продавцов**: авто‑ответы своим покупателям, поднятие своих лотов, выдача своих
товаров.

Продажа, цены, тексты объявления, монетизация и защита — в `SELLING.md`.
