# FunPay Assistant — как продавать, монетизация и защита

Файл для **вас как продавца**. Не кладите его и папку `tools/` в архив покупателю.

---

## 1. Почему это хорошо продаётся на FunPay

По индексу рынка (RMTHub) и гайдам продавцов топ‑спрос — игровые аккаунты,
валюта, буст, ключи/подписки. Но **самый умный товар — софт для самих
продавцов**: боты авто‑поднятия/авто‑ответа/авто‑выдачи (Cardinal, Vertex,
Cortex). Вы продаёте «лопаты золотоискателям» — покупает вся аудитория FunPay.

**Заголовок:** FunPay Assistant — бот авто‑поднятия лотов, авто‑ответов и

**Текст:**

> автоматически выдаёт ключи/товар сразу после оплаты. Продажи идут, даже пока
> вы спите.

> ✅ Авто‑ответчик с шаблонами по ключевым словам
> ✅ Авто‑выдача ключей со склада или по шаблону
> ✅ Windows‑программа, ставится в 2 клика, Python не нужен
> ✅ Данные и golden_key хранятся только на вашем ПК (зашифрованы)
> ✅ Демо‑режим — попробуйте до покупки
>
> Разовая покупка — работает навсегда. Помогу с настройкой.

**Оффер:** «Пришлю установщик + активирую лицензию за 5 минут после оплаты».

## 3. Монетизация

**Разовая покупка (лицензия на 1 ПК):**
- База: 1200–1800 грн — программа + инструкция.
- Стандарт: 2500–3000 грн — + настройка шаблонов/склада под клиента.
- Премиум: 4000–5000 грн — + помощь с golden_key, шаблоны под его товары,
  1 месяц поддержки.

**Подписка (recurring):** лицензия со сроком (`--expires`):
- 250–400 грн/мес или 2000–3000 грн/год.
- Продление = новый ключ с новой датой.

**Допы:** настройка «под ключ» +500–1000 грн; пакет готовых шаблонов
авто‑ответов +500 грн.

**Где продавать:** FunPay (категория «услуги/софт» в популярных играх),
Telegram‑чаты продавцов, Playerok, форумы.

## 4. Защита от бесплатного копирования (Ed25519)

Лицензии подписываются вашим приватным ключом, приложение проверяет их
публичным. Без приватного ключа лицензию **невозможно подделать**.

**Шаг 1 (один раз) — свои ключи:**
```bash
python tools/keygen.py
```
- `PUBLIC_KEY_HEX` → в `src/funpay_assistant/licensing.py`.
- `PRIVATE_KEY_HEX` → в `tools/seller_private_key.txt` (в комплекте тестовый —
  обязательно замените своим перед продажами).

**Шаг 2 — ключ покупателю:**
```bash
python tools/issue_license.py --name "Иван"                     # бессрочно
python tools/issue_license.py --name "Иван" --expires 2027-01-01  # подписка
python tools/issue_license.py --name "Иван" --machine <ID_ПК>     # привязка к ПК
```
ID ПК покупатель видит во вкладке «Лицензия».

**Что защищает:**
- Подделать ключ нельзя (криптоподпись).
- `--machine` — 1 ключ не работает на многих ПК.
- `--expires` — подписочная модель.
- Демо‑режим ограничивает live‑функции до активации.

**Не отдавайте покупателю:** папку `tools/`, файл `seller_private_key.txt`,
этот `SELLING.md`. Отдаёте только собранный `FunPayAssistant-Setup.exe`.

## 5. Чек‑лист перед первой продажей
1. `python tools/keygen.py` → вставил свой публичный ключ, сохранил приватный.
2. Собрал `.exe` через GitHub Actions (или локально на Windows).
3. Проверил демо‑режим и активацию лицензии.
4. Подготовил архив покупателю: только установщик (+ короткая инструкция).
5. Разместил объявление с текстом из раздела 2.
