# 🎮 FunPay AutoResponder

**Премиальный кросс-платформенный автоответчик для FunPay** с современным
тёмным интерфейсом, умными правилами, шаблонами сообщений, интеграцией с
локальным ИИ, работой в системном трее и защитой от бана.

> 🇬🇧 English version: [README_EN.md](README_EN.md)

---

## ✨ Возможности

| Категория | Что умеет |
|-----------|-----------|
| 🖥️ **Интерфейс** | CustomTkinter, тёмная/светлая тема + 5 акцентных палитр (glass/neumorphism), русский и английский языки, плавные карточки, тосты, тултипы |
| ⚡ **Автоответы** | Правила с приоритетами: ключевые слова, «содержит», точное совпадение, регулярные выражения, catch-all |
| 📝 **Шаблоны** | Переменные `{username}`, `{game}`, `{price}` и др., генерация через ИИ |
| 🤖 **ИИ** | Локальные модели через **Ollama** или **LM Studio**: ответы, генерация шаблонов, подсказки лучших ответов |
| 🛡️ **Анти-бан** | Случайные задержки опроса (3–8 c) и ответа (8–25 c), «человеческий» разброс, имитация набора текста, cooldown по чатам |
| 🎯 **Режимы** | «Только новые диалоги», «Все чаты», «Только определённые игры», чёрный/белый список |
| 🌐 **Сеть** | Headless-браузер (Playwright), прокси HTTP/SOCKS5 |
| 🔔 **Уведомления** | Системные уведомления с превью + звук |
| 📊 **Статистика** | Обработано / отвечено / заработано, график по дням, топ правил |
| 🧩 **Плагины** | Простая система плагинов (трансформация ответов, хуки) |
| 📦 **Прочее** | Экспорт/импорт настроек (JSON), автозапуск, авто-проверка обновлений, трей, безопасное хранение секретов (keyring) |

## 🚀 Установка

### Вариант 1. Установщик Windows (рекомендуется для пользователей)

1. Скачайте `FunPayAutoResponder-Setup-x.x.x.exe` из раздела Releases.
2. Запустите установщик и следуйте мастеру (можно включить ярлык на рабочем
   столе и автозапуск).
3. Приложение установится в `C:\Program Files\FunPay AutoResponder`.

### Вариант 2. Из исходников (все платформы)

Требуется **Python 3.11+**.

```bash
git clone <repo-url> FunPay-AutoResponder
cd FunPay-AutoResponder

python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux / macOS:
source .venv/bin/activate

pip install -r requirements.txt
python scripts/generate_assets.py          # иконки и звук
python -m playwright install chromium       # браузер для реального режима

python src/main.py
```

> 💡 **Демо-режим.** Если аккаунт не настроен или Playwright недоступен,
> приложение запускается в безопасном демо-режиме и генерирует «виртуальные»
> сообщения — так можно всё изучить без реального входа.

### Сборка исполняемого файла

```bash
# Windows
build.bat

# Linux / macOS
./build.sh
```

Готовый бандл появится в `dist/FunPayAutoResponder/`.
Для установщика Windows скомпилируйте `installer/setup.iss` в **Inno Setup 6+**
(`iscc installer\setup.iss`).

## 🔑 Настройка аккаунта FunPay

Рекомендуемый способ входа — через cookie **`golden_key`** (стабильнее, чем
логин/пароль, и не требует ввода капчи).

**Как получить `golden_key`:**

1. Войдите на [funpay.com](https://funpay.com) в браузере.
2. Откройте DevTools (`F12`) → вкладка **Application/Storage** → **Cookies** →
   `https://funpay.com`.
3. Найдите cookie с именем **`golden_key`** и скопируйте его значение.
4. В приложении: **Настройки → Аккаунт FunPay** → вставьте значение в поле
   `golden_key` → **Проверить вход**.

Либо укажите логин и пароль в тех же настройках (менее стабильно из-за защиты).

> 🔒 Секреты (пароль, `golden_key`, пароль прокси) хранятся в системном
> хранилище ключей ОС (keyring), а не в открытом виде.

## 📏 Как создать первое правило

1. Вкладка **Автоответы → ➕ Добавить правило**.
2. Заполните:
   - **Название** — например, «Приветствие».
   - **Тип совпадения** — `keyword` (ключевые слова).
   - **Шаблон / ключевые слова** — `привет, здравствуй, hello`.
   - **Ответ** — имя шаблона (`greeting`) **или** текст с переменными:
     `Здравствуйте, {username}! Чем помочь?`
   - **Приоритет** — больше = раньше проверяется (напр. `200`).
   - **Cooldown** — минимальный интервал ответа в этот чат (сек), 0 = без ограничения.
3. **Сохранить**. Правило появится в списке; переключатель включает/выключает его.

Приложение уже содержит несколько готовых правил и шаблонов — их можно
редактировать.

## 🛡️ Советы по анти-бану

- **Не занижайте задержки.** Оставьте опрос `3–8 c` и ответ `8–25 c` — это
  имитирует живого человека. Слишком быстрые ответы = красный флаг.
- **Включите «человеческий разброс»** и «имитацию набора текста» (Настройки →
  Задержки).
- **Не отвечайте на всё подряд.** Используйте режим «Только новые диалоги» или
  фильтр по играм, чтобы не спамить.
- **Задайте cooldown** на catch-all правила, чтобы не заваливать один чат.
- **Используйте прокси** и стабильный аккаунт; не запускайте несколько ботов с
  одного IP.
- **Не оставляйте бота 24/7** без пауз — периодически заходите вручную.
- Начинайте с малого: 1–2 правила, наблюдайте за поведением, потом расширяйте.

## 🤖 Подключение ИИ (опционально)

**Ollama:**
```bash
# установите Ollama (https://ollama.com), затем:
ollama pull llama3.1
ollama serve   # обычно уже запущен
```
В приложении: **Настройки → Искусственный интеллект** → backend `ollama`,
URL `http://localhost:11434`, модель `llama3.1` → **Ping**.

**LM Studio:** запустите локальный сервер (порт `1234`), выберите backend
`lmstudio`, URL `http://localhost:1234`.

Опция **«Использовать ИИ только когда не сработало ни одно правило»** оставляет
приоритет за вашими правилами, а ИИ подключается лишь как запасной вариант.

## 🧩 Плагины

Положите `.py`-файл в папку `plugins/` с классом-наследником `Plugin`:

```python
from src.core.plugins import Plugin

class SignaturePlugin(Plugin):
    name = "Signature"
    enabled = True
    def on_before_send(self, message, reply):
        return reply + "\n\nС уважением, продавец"
```

Хуки: `on_load`, `on_start`, `on_stop`, `on_message`, `on_before_send`.

## ❓ FAQ

**Приложение свернулось и пропало.** Оно ушло в системный трей. Кликните по
иконке в трее (левый клик — открыть, правый — меню).

**Ничего не отвечает / статус «Остановлен».** Нажмите **Запустить**. Проверьте,
что настроен аккаунт и вход проходит (кнопка «Проверить вход»).

**Отвечает не сразу.** Так и задумано — задержка 8–25 c для защиты от бана.
Настраивается в разделе «Задержки».

**Selectors errors в логах.** FunPay мог изменить вёрстку. Селекторы собраны в
`src/browser/funpay_client.py` (класс `Selectors`) — обновите их там.

**Где логи?** Вкладка «Логи» в реальном времени + файл в `data/logs/`.

**Как перенести настройки?** Настройки → Экспорт/Импорт (JSON).
