## 2. Цены и монетизация

### Разовая покупка (десктоп‑лицензия)
- **Базовая**: 1000–1500 грн — бессрочная лицензия на 1 ПК.
- **Стандарт**: 2000–2500 грн — лицензия + помощь с установкой + настройка
  под компанию (реквизиты, логотип, шаблон).
- **Премиум**: 3500–5000 грн — установка на VPS/домен (SaaS для команды) +
  брендирование + 1 месяц поддержки.

### Подписка (recurring)
- Выпускайте лицензию с датой окончания (`--expires`) на 1/3/12 месяцев.
- 149–299 грн/мес или 990–1990 грн/год.
- Продление = выпуск нового ключа с новой датой.

### Доп‑заработок
- Настройка «под ключ» для клиента: +500–1000 грн.
- Кастомный шаблон PDF под фирменный стиль: +700–1500 грн.
- Размещение на VPS с доменом: +1000–2000 грн разово или в подписку.

### Где продавать
FunPay, OLX, Prom, Telegram‑каналы для ФОП/фрилансеров, тематические чаты,
Kwork/Freelancehunt (как «настрою программу для счетов»).

## 3. Как выпускать лицензии (защита от копирования)

Механизм: **цифровая подпись Ed25519**. Приватный ключ только у вас,
публичный зашит в программе. Клиент не может подделать ключ.

### Шаг 1 (один раз) — свои ключи
```bash
python tools/keygen.py
```
- `PUBLIC_KEY_HEX` вставьте в `app/licensing.py` (константа PUBLIC_KEY_HEX).
- `PRIVATE_KEY_HEX` запишите в `tools/seller_private_key.txt`.

> В комплекте уже есть рабочая пара ключей для теста. Для реальных продаж
> **обязательно сгенерируйте свою** — иначе чужие смогут выпускать ключи.

### Шаг 2 — выпуск ключа покупателю
```bash
# бессрочно
python tools/issue_license.py --name "Иван Петров"

# подписка до даты
python tools/issue_license.py --name "ООО Ромашка" --expires 2027-01-01

# привязка к конкретному ПК (ID виден на странице /activate у клиента)
python tools/issue_license.py --name "Клиент" --machine 3f9a1b2c4d5e6f70
```
Полученную строку `IFG1....` отправляете покупателю. Он вставляет её в
разделе **«Активировать лицензию»**.

### Как это защищает
- Без приватного ключа лицензию **невозможно сгенерировать** (криптоподпись).
- Привязка к ПК (`--machine`) не даёт использовать 1 ключ на многих машинах.
- Срок действия (`--expires`) превращает продукт в подписку.
- Демо‑режим ограничивает функционал до покупки (лимиты + водяной знак).

### Что НЕ отдавать покупателю
- папку `tools/` (генерация ключей),
- файл `tools/seller_private_key.txt`,
- этот файл `SELLING.md`.

Отдаёте только папку `app/`, `requirements.txt`, `run.*`, `README.md`, `.env.example`.
